# THE TRENDING FONT LIBRARY (2026 Edition)

> Reference for TYPESET agent. Fonts are matched to brand theme, never generic, never the AI-bottleneck defaults.
> Rotation rule: NEVER reuse the same combination across consecutive projects.

## BANNED FONTS (The Bottleneck)

These are the fonts AI models reach for by default. Using them makes a site instantly look generated:

| Banned Font | Why It Is Banned |
|---|---|
| Inter (as default) | The #1 AI default. Acceptable ONLY on explicit user request for neutral feel |
| Roboto | Android system font. Zero brand character |
| Arial / Helvetica | System fallbacks. The "I gave up" choice |
| Open Sans | Generic body font of the 2010s |
| Times New Roman / Georgia | System serifs with no art direction |
| Fraunces | The #1 AI-favorite display serif |
| Instrument Serif | The #2 AI-favorite display serif |

## THE WEIGHT HIERARCHY RULE

Never ship only Regular (400) and Bold (700). A premium type system uses the full range:

| Weight | Name | Use |
|---|---|---|
| 300 | Light | Large display text where elegance matters |
| 400 | Regular | Body copy |
| 500 | Medium | Subtle emphasis, navigation, buttons |
| 600 | SemiBold | Subheadlines, card titles, strong labels |
| 700 | Bold | Headlines, primary emphasis |
| 800+ | ExtraBold/Black | Massive display statements only |

## LOADING RULES

1. **Next.js:** always `next/font` (self-hosted, zero layout shift)
2. **Vanilla/Vite:** `@font-face` + `font-display: swap`, self-hosted
3. **NEVER** link Google Fonts via `<link>` in production (render-blocking, privacy)
4. Reserve fallback metric space to prevent CLS: `size-adjust` in @font-face fallbacks
5. Variable fonts preferred (one file, full weight range, animatable weight)

## EMOJI POLICY

Discouraged by default in code, markup, and visible text. Replace with icon-library glyphs (Phosphor, HugeIcons).
Override: allowed only when user explicitly asks for playful/chat-style vibe, sparingly, with intent.
